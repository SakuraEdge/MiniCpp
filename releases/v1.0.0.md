# Mini C++ Rev v1.0.0

Mini C++ 的首个正式版本，面向 Windows 10/11 x64。离线安装包内置 GCC 和 GDB，安装到当前用户目录，无需管理员权限。运行需要 .NET Framework 4.8 或更新版本。

- 运行记录分别显示程序输入、标准输出和标准错误。长记录支持展开和分页，默认字号为 14 pt。
- 编辑器字号在调整后保存，多窗口退出时会合并各自修改的设置。
- 单文件竞赛模板新增 `/solve`。更新检查在 GitHub API 限流时改用公开订阅，正式版跟踪正式发行通道。
- Mini C++ 自有代码和资源采用 MIT 许可证。安装包随附 MIT 文本和第三方许可声明。

Dev v1.0.3 的内置更新检查按版本数字比较。从该开发版切换时，请关闭程序，并从本页下载安装包。开发版与正式版沿用同一个安装目录。
