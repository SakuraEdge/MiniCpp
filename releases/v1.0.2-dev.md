• 代码编辑区的光标从 1 像素加粗到 2 像素，高缩放屏幕上最多为 3 像素。
• 修复 emoji 输入、显示及表情后选区错位的问题。可从 Windows 表情面板输入，也可粘贴；UTF-8 源文件保存后仍保留原表情。
• 编译自己的源文件时，错误行和行号会标红；编辑代码或重新编译后会清除旧标记。
• 工具栏新增亮色与暗色主题切换，编辑器、语法高亮、菜单和输出面板一起渐变，并记住上次的选择。
• 单文件竞赛框架支持快捷展开，包含标准输入输出和 freopen 文件输入输出两种模板。
• 行号居中，断点在行号原位显示；支持括号自动配对、关键字加粗、绿色预处理指令和红色运算符。
• 「帮助 → 检查更新」无需登录即可查看 GitHub 发布说明，安装最新版本后也可回看本次变化。

Windows x64 离线安装包内置 GCC 和 GDB，适用于 Windows 10/11（.NET Framework 4.8 或更新版本）。
