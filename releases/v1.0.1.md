# Mini C++ Rev v1.0.1

- 安装向导新增目录选择页。首次安装默认使用当前用户目录，升级时默认沿用上次安装的位置，也可手动选择有写入权限的目录。
- 安装时可创建桌面快捷方式，默认勾选。开始菜单会添加 Mini C++ 快捷方式。
- 安装完成时可勾选「查看开始菜单快捷方式」。在资源管理器中右键单击选中的快捷方式，选择「固定到开始」。
- 更换为新的 Mini C++ 图标：淡蓝圆角底，上方 M，下方 C++。软件、安装包、卸载程序和快捷方式统一使用新图标。
- 新增免安装版 `MiniCpp-Rev-v1.0.1-win-x64-Portable.zip`，内置 GCC 和 GDB。完整解压后运行文件夹内的 `MiniCpp.exe`。
- 免安装版首次启动可选择创建桌面快捷方式，以及将 `.cpp` 默认打开方式设为当前免安装版；默认应用需在 Windows 设置中确认。后续可从「设置 → 免安装版设置」再次调整。

免安装版请完整解压到英文路径，例如 `D:\Tools\MiniCpp`，路径可含空格。内置 GCC 在部分 Windows 系统的中文解压路径下会发生链接错误。设置和编译缓存保存在 `%LOCALAPPDATA%\MiniCpp`。

如需迁移现有安装，请先卸载旧版本，再选择新目录安装。
