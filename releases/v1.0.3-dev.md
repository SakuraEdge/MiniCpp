• 「运行输出」分成输入和输出两个窗格：宽窗口左右排列，半屏或窄窗口上下排列。输入完整保留；超过 10 行的输出默认只显示前三行和末行，可展开，过长的内容可翻页。
• 程序写到标准错误的内容可在输出窗格单独切换查看，不会混进答案；退出码显示在状态栏。
• 运行输入与输出的默认字号调大到 14 pt，可在「设置 → 字体大小」调整，也可从底部面板右侧的设置图标打开。
• 修复代码字号重新打开后变回原样的问题：按住 Ctrl 滚动滚轮调整的字号现在会保存；同时打开多个窗口时，后退出的窗口不再覆盖刚保存的字号。
• 修复「检查更新」提示 GitHub 拒绝访问或达到请求限额的问题：匿名接口被限流时改读同一仓库的公开发布订阅，仍可看到版本和更新说明。
• 竞赛框架快捷展开新增一种带空 solve() 函数的模板，展开后光标停在 solve() 函数体内。
• 编译前读取源文件、准备临时文件和启动 GCC 改在后台进行，不再占用界面线程。

Windows x64 离线安装包内置 GCC 和 GDB，适用于 Windows 10/11（.NET Framework 4.8 或更新版本）。安装包由 GitHub 上的构建流程从本版本的源码生成。
