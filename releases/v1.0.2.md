# Mini C++ Rev v1.0.2

- 新增「设置 → 框架与快捷指令」。可编辑新建文件的初始框架，新增、重命名或删除 `/命令`，修改对应 C++ 代码，并用 `${cursor}` 指定插入后的光标位置。
- 保留 `/main`、`/fremain`、`/solve` 默认模板。指令完整输入后按回车执行，框架和指令设置会保存。
- 翻新更新窗口，集中显示当前版本、新版本说明、下载进度、取消与重试。
- 从 v1.0.2 起支持「下载并更新」。自动下载小型更新包、校验 SHA-256，保存当前源码后退出、替换程序并重启，恢复已保存源码标签。安装版和免安装版均支持。
- 更新只替换程序清单中的文件，保留源码、模板、偏好、工具链、快捷方式和免安装标记。替换失败时回滚，并提供诊断记录。

v1.0.1 的检查更新尚无自动安装功能，请先从本页下载安装包或免安装版升级到 v1.0.2。程序目录需有当前用户写入权限，更新前需结束运行或调试并关闭同一目录的其他窗口。工具链版本变化时使用完整安装包或免安装包。

完整免安装版内置 GCC/GDB，请完整解压到英文路径，例如 `D:\Tools\MiniCpp`，路径可含空格。内置 GCC 在部分系统的中文路径下仍可能出现链接错误。

此版本未进行代码签名。更新包和校验信息由本仓库通过 HTTPS 提供。
